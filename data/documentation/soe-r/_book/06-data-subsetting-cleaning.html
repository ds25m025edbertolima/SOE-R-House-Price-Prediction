Restrict the features to: - land square feet - waterfront type - view quality - electricity availability - water availability - street type - coordinates (longitude, latitude)

Cleaning

We obtain the dataset with selected features. Now we go ahead to prepare the data for initial exploratory data analysis.

Code 
df_all <- df_all %>% 
  select( -property_type)

We first select lands with buildings on it, as we are interested in residential home valuations.

Code 
df_all <- df_all %>% 
  filter(buildings != 0)

Then we look at the missing values and treat them one-by-one.

Code 
colSums(is.na(df_all))

We remove observations that have no bedroom or bathroom recorded as these would be one of the features easiest for the user to input and we want to use them. If they are missing it likely hints at a data recording issue or a building type that is not a classical residential home (which is out of scope for this project).

Code 
df_all <- df_all %>% 
  filter(!is.na(bathrooms))

We also remove the 5 observations missing coordinates or square footage.

Code 
df_all <- df_all %>% 
  filter(!is.na(latitude) & !is.na(longitude) & !is.na(land_net_squarefeet))

Waterfront type records River, Lake, Stream/Creek or Salt. We fill in missing values to represent no waterfront, as such category does not exist and missing specification likely represents that the property ahs no direct water connection.

Code 
df_all <- df_all %>% 
  mutate(waterfront_type = replace_na(waterfront_type, "None"))
unique(df_all$waterfront_type)

View quality currently has 9 categories that is slightly excessive, and more confusing for the potential user and increases model complexity.

We collapse the categories into “limited”, “average”, “good”, “very good”. We replace NAs with uncategorized.

Code 
df_all <- df_all %>%
  mutate(
    view_quality = replace_na(view_quality, "uncategorized"),

    view_quality = fct_collapse(view_quality,
      "limited"   = c("View Lim", "View Lim -", "View Lim +"),
      "average"   = c("View Avg", "View Avg +"),
      "good"      = c("View Good", "View Good +"),
      "very good" = c("View V-Good", "View V-Good +")
    )
  )
unique(df_all$view_quality)

We order the view types.

Code 
df_all$view_quality <- factor(df_all$view_quality, 
                               levels = c("uncategorized", "limited", "average", "good", "very good"),
                               ordered = TRUE)

For the year remodeled, we will proceed as no remodeling happened, if the year is not recorded.

Code 
df_all <- df_all %>% 
  mutate(year_remodeled = replace_na(year_remodeled, 0))

Lastly, in the units feature we convert the few missing values to 1 unit after looking into the data manually, and also convert 0 units to 1 as the empirical meaning of having no separate units and the whole unit being one (for example family home) is the same.

Code 
df_all <- df_all %>%
  mutate(units = if_else(is.na(units) | units == 0, 1, units))

We have now the complete dataset with the preselected features.

colSums(is.na(df_all))
