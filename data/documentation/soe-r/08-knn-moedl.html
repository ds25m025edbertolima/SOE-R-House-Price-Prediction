KNN model

One of the models we decided to try is KNN. The underlying reason is that similar real estates within the same area tend to converge in price. Another advantage of a KNN model that is based on a very few features (one of them being location in the form of longitude and latitude) is the easy explanation and nice visualization it offers to the users. An example would be to display on a map the closest, most similar properties on the market.

Minimal model

We will first attempt to fit a KNN model with using only longitude, latitude and the net square footage of properties.

baseline_data <- df_all %>% 
  select(
    total_market_value_current_year, 
    latitude, 
    longitude, 
    land_net_squarefeet
  ) %>% 
  drop_na() # in case, but no NA

set.seed(222) 
train_index <- createDataPartition(
  baseline_data$total_market_value_current_year, 
  p = 0.8, 
  list = FALSE
)

train_data_1 <- baseline_data[train_index, ]
test_data_1  <- baseline_data[-train_index, ]

We try for different values of k (2, 3, 4, 5). We decided these values as in a map visualization (showing the closest observations to the user) more than 5 similar properties displayed would compromise the user experience.

cv_control <- trainControl(
  method = "cv", 
  number = 3
)

k_grid <- data.frame(k = c(2, 3, 4, 5))

set.seed(222)
knn_baseline <- train(
  total_market_value_current_year ~ latitude + longitude + land_net_squarefeet,
  data = train_data_1,
  method = "knn",                  # Back to the fast, standard method
  trControl = cv_control,
  preProcess = c("center", "scale"),
  tuneGrid = k_grid
)
